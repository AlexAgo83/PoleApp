## Fondations MVP (global)

### Multi-device

- **Application accessible sur téléphone + ordinateur** (responsive web app / app + web).
- Objectif : usage admin et cours VOD souvent sur ordi, élève et prof souvent sur mobile.

### Navigation & logique des pages

- **Le bouton “Accueil” est confusing car il ne renvoie pas à la Home Page**,mais à la page “Évolution de l’app” qui ne devrait pas s'afficher
- Ajouter une navigation claire :
    - **Icône “maison”** (retour Home)
    - **Divers onglets en tête de pag** (ou barre latérale sur desktop) pour passer vite entre les onglets

### UI / UX

- **Refonte UI/UX** : hiérarchie visuelle, cohérence, composants réutilisables.
- Créer un **univers graphique fort** (couleurs, typo, iconographie, style “pole dance / énergie / progression”).

### Page de login / onboarding

- Sur la page de login : permettre de
    - **Créer un compte**
    - **Choisir son profil** (Élève / Prof / Admin)
    - **Choisir sa version** : Freemium / Premium (au moins pour Élève + Prof si concerné)

## 2) Vue PROF

### 2.1 Règles d’accès (hyper important)

- Un prof **ne voit que** les fiches élèves **à qui il a enseigné** ou **avec qui il a un cours prévu** (pas tous les élèves de l’école)
- Le prof **n’a pas accès** à la gestion admin de l’école.

### 2.2 Prof multi-écoles

- Dashboard prof : liste des cours à venir / à préparer
- Filtres / tris :
    - École
    - Date
    - Discipline

### 2.3 Onglet “Positions” (côté prof)

- Le prof peut **ajouter des positions** qu’il va enseigner : minimum requis : **nom + photo**
- Accès gratuit prof accès au catalogue positions + explications + vidéos
- Accès aux jeux de révision : **tous les jeux** accessibles

### 2.4 Onglet “Cours”

**Générateur & suggestion**

- Ajouter :
    - **générateur de cours** adapté aux élèves + niveaux
    - module de suggestion de prochains cours

**Fiche cours**

- Ajouter dans chaque fiche :
    - école
    - studio
    - niveau
    - discipline
    - prof
    - heure
    - liste des élèves présents

**Générateur : forcer des choix**

- Possibilité d’ajouter des “souhaits / positions imposées”
- L’app adapte le reste du contenu autour

**Création fiche élève depuis le cours**

- Depuis une fiche cours :le prof et l'admin doivent  pouvoir créer une fiche élève “à la volée”

**Notes prof privées**

- Permettre au prof d’ajouter des notes sur une fiche élève
- Non visible par l’élève

### 2.5 Onglet “Suivi de facturation”

- À ajouter : dashboard de suivi des facture te des regèlent pour aider les profs à générer leur facturation auprès des écoles. Le Dashboard liste tous les cours donnés et peut indiqué si le prof a envoyé sa facture et si il a été payé, il peut meme générer sa facture depuis l'app qui est directement envoyée à l'école concernée

### 2.6 Onglet “Élèves” (côté prof)

- Dans les fiches élèves : enlever le doublon “niveau atteint” qui est en double
- Remplacer le texte par **code couleur** (plus lisible)
- Ajouter pour chaque position :
    - **combien de fois** le trick a été enseigné / vu
    - logique : à chaque fois que vu → ajouter un “point” / marqueur de couleur (ou compteur + code couleur)

### 2.7 Fiche Prof visible par les élèves

- Pouvoir créer une fiche prof de présentation avec photo (diplôme obtenu, parcours, position préférées etc.)
- Visible par les élèves (dans l’école / studio concerné)

### 2.8 Onglet “Jeu / Révision”

- À ajouter côté prof

- Premium :
    - accès à **toutes** les positions avec leur vidéos, explications
    - accusé aux videos en streaming
