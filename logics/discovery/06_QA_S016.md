## Login
# Création de compte
Le nom est prénom n'est plus optionnel. (S'assurer que l'app utilise nom / prenom et pas un truc comme username)
Le mot de passe doit être tapé deux fois pour vérifier qu'on a pas tapé une erreur
Il faut un petit oeil pour voir le mot de passe en clair dans le champs de text
A la création il faut dire à l'utilisateur qu'il doit vérifier son courier et en // envoyer un mail de verification sur l'adresse saisie.
Ce mail permettra de "vérifier" l'utilisateur.
Un utilisateur ne peut se logger que si il est "vérifié".
pouvoir forcer la vérification en super-admin et permettre de renvoyer un mail de vérification.

# Changer de mot de passe
L'utilisateur doit pouvoir editer un nouveau mot de passe dans son profile.

## Archivage & rôles
Pouvoir désactiver un studio (Admin) ; il n'apparait plus pour les utilisateurs ; il n'est pas supprimé mais on ne peut plus le sélectionner si il n'est pas nécessaire.
Pouvoir désactiver une discipline (Admin) ; elle n'apparait plus pour les utilisateurs ; elle n'est pas supprimée mais on ne peut plus le sélectionner si elle n'est pas nécessaire.
Pouvoir désactiver un utilisateur (Admin/super-admin) ; l'admin peut couper l'accès à un eleves et un professeur. le super-admin peut couper l'accès à un admin.

## Professeurs
Un professeur doit avoir le droit de créer une position et/ou un preset ; le droit est donné par l'admin ; par défaut il a le droit.
Le professeur peut indiquer ses disciplines favorites (comme pour les positions coups de coeu).
