# 08_DRY_013 — Harmonisation padding/gap des panels
[Aligné v0.13.0 | Confiance: 85% | Avancement: 0% | Portée: UI spacing panels]

Objectif : définir un pattern commun pour les panels “principaux” (dashboards, modules/actions, sections clés, headers de page) afin d’aligner le padding/gap interne et faciliter les ajustements ultérieurs via des valeurs partagées.

## Pattern proposé
- Variables utilitaires (CSS) pour le spacing panel :
  - `--panel-px: 1.25rem` (p-5) ; `--panel-py: 1.25rem`.
  - `--panel-gap: 0.75rem` (space-y-3 / gap-3), `--panel-gap-lg: 1.25rem` (space-y-5 / gap-5).
- Classe utilitaire (globale CSS) à introduire : `.panel-body { padding: var(--panel-py) var(--panel-px); display: flex; flex-direction: column; gap: var(--panel-gap); }` + variante `.panel-body.lg-gap { gap: var(--panel-gap-lg); }`. Option si grille : `.panel-grid { display: grid; gap: var(--panel-gap); }`.
- Typo standard : titre `text-lg font-semibold text-white`, sous-titre `text-xs uppercase tracking-[0.14em] text-cyan-200`.

## Cibles prioritaires (modules/actions)
- Dashboards admin/teacher/student : cartes “modules” / “actions rapides”.
- Panels sections `/admin` (modules écoles, users, studios), `/teacher` (modules cours/positions), `/student` (modules école/cours).
- Header modules super-admin (actions packs/abos) si non aligné.
- `/admin/school` : header + sections repliables (CollapsibleSection) + onglets école/studios/partenaires.
- `/teacher/students/[id]` et `/teachers/[id]` : sections Édition/Photo + panels infos.
- Panels listes denses (cours/positions/stats) : appliquer le padding commun seulement si la densité reste acceptable.

## Étapes
1) Ajouter les utilitaires globaux (variables + classes `.panel-body`, `.panel-body.lg-gap`, `.panel-grid`) + guidelines d’usage (quand éviter sur listes ultra denses).
2) Appliquer sur les panels modules/actions des dashboards (remplacer padding custom par `.panel-body`).
3) Appliquer sur sections clés : `/admin/school` (header + sections repliables), `/teacher/students/[id]`, `/teachers/[id]`, modules admin/teacher/student.
4) Ajuster les headers FoxPageHeader/panels modules si besoin d’aligner le padding top/bottom.
5) QA visuelle desktop/mobile (pas de régression de densité sur listes denses).

## Reste à confirmer
- Quel gap par défaut pour les listes denses ? (peut-être conserver padding existant sur tableaux/listes).
- Maintenir exceptions sur formulaires très compacts (ex. filtres denses) en gardant l’ancien padding si nécessaire.
