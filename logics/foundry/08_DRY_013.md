# 08_DRY_013 — Harmonisation padding/gap des panels
[Aligné v0.13.0 | Confiance: 90% | Avancement: 72% | Portée: UI spacing panels | Obsolete]

Objectif : définir un pattern commun pour les panels “principaux” (dashboards, modules/actions, sections clés, headers de page) afin d’aligner le padding/gap interne et faciliter les ajustements ultérieurs via des valeurs partagées.

## Pattern proposé
- Variables utilitaires (CSS) pour le spacing panel (ajoutées dans `app/globals.css`) :
  - `--panel-px: 1.25rem` (p-5) ; `--panel-py: 1.25rem`.
  - `--panel-gap: 0.75rem` (space-y-3 / gap-3), `--panel-gap-lg: 1.25rem` (space-y-5 / gap-5).
- Classes utilitaires (globales) ajoutées :
  - `.panel-body { padding: var(--panel-py) var(--panel-px); display: flex; flex-direction: column; gap: var(--panel-gap); }`
  - `.panel-body.lg-gap { gap: var(--panel-gap-lg); }`
  - `.panel-grid { display: grid; gap: var(--panel-gap); }` + `.panel-grid.lg-gap { gap: var(--panel-gap-lg); }`
- Typo standard (suggestion) : titre `text-lg font-semibold text-white`, sous-titre `text-xs uppercase tracking-[0.14em] text-cyan-200`.

## Cibles prioritaires (modules/actions)
- Dashboards admin/teacher/student : cartes “modules” / “actions rapides”.
- Panels sections `/admin` (modules écoles, users, studios), `/teacher` (modules cours/positions), `/student` (modules école/cours).
- Header modules super-admin (actions packs/abos) si non aligné.
- `/admin/school` : header + sections repliables (CollapsibleSection) + onglets école/studios/partenaires.
- `/teacher/students/[id]` et `/teachers/[id]` : sections Édition/Photo + panels infos.
- Panels listes denses (cours/positions/stats) : appliquer le padding commun seulement si la densité reste acceptable.

## Étapes

2) (Fait) Appliquer sur les panels modules/actions des dashboards (admin / teacher / student).
3) (En cours) Appliquer sur sections clés : `/admin/school` (header + sections repliables), `/teacher/students/[id]`, `/teacher/students` (listes), `/teachers/[id]`, modules admin/teacher/student restants.

5) QA visuelle desktop/mobile (densité OK, pas d overlaps).
