# 08 — DRY plan (Super Admin)
[Aligné v0.7.8 | Confiance: ~80% | Avancement: 75% | Temps restant estimé: 2-3H]
Contexte :
- Mettre en place l’espace Super Admin global (hors écoles) pour gérer écoles, admins, abonnements/packs, TVA/devise, avec RBAC strict et audit.
- Scope : création/suppression/archivage d’écoles, assignation admin école, offres (abos/packs) globales (EUR, TVA 20%), promotion/dégrado SUPER_ADMIN en secours. Pas d’impersonation.

## Plan
- [x] Cadre & RBAC
  - Définir le rôle SUPER_ADMIN (pas d’impersonation école), routes /super-admin protégées, redirect 403/redirect.
  - Seed idempotent : créer un SUPER_ADMIN par défaut si aucun (env `SUPER_ADMIN_EMAIL`/`SUPER_ADMIN_PASSWORD`), sinon no-op.
  - Promo/dégrado : route/écran protégé pour promouvoir/dégrader un user en SUPER_ADMIN via recherche email + warning + audit.
- [x] Dashboard Super Admin
  - Home super admin : liste des écoles (nom, admins, statut actif/archivé), CTA créer/archiver, lien détail école.
  - Détail école : infos de base (nom, site, admins assignés), bouton reset/assignation admin.
- [x] Offres globales (abonnements/packs)
  - Abos globaux (EUR, TVA 20% par défaut) : nom, prix mensuel/annuel TTC, crédits mensuels (1000 défaut), TVA %, engagement (mensuel/annuel), actif/ouvert, ordre. Saisie/édition/suppression.
  - Packs crédits globaux : nom, crédits inclus, prix TTC, TVA %, ordre, actif/ouvert. Valeurs de départ : Pack 500 (9,99), 1000 (14,99), 2500 (29,99).
  - Paramètres globaux : TVA par défaut (20%), devise (EUR).
- [x] Audit & sécurité
  - Audit log des actions super-admin : création/suppression/archivage école, assignation admin, création/édition/suppression offres, promo/dégrado.
  - Prévoir flag 2FA (à activer plus tard) ; UI warning sur comptes super-admin.
- [ ] Out of scope
  - Pas d’impersonation/switch vers un admin d’école.
  - Pas de paiement réel ; offres globales appliquées telles quelles aux écoles (override école plus tard).
