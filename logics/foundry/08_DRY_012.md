# DRY – Harmoniser l’espacement des panneaux `<details>/<summary>` (mb -> mt du contenu)
[Aligné v0.12.11 | Confiance: 90% | Avancement: 100% | Portée: UI spacing]

Objectif : pour chaque panneau collapsable où un `<summary>` est immédiatement suivi d’un `<div>` de contenu, déplacer la marge basse du `<summary>` vers une marge haute sur le `<div>` qui suit, afin de garder un espacement cohérent sans décaler le titre.

## Actions réalisées
- Règle globale CSS : `details > summary + * { margin-top: 0.75rem; }` pour créer l’espace sous le summary, suppression du margin-bottom forcé et des `space-y` sur `<details>`.
- Components : `FilterPanel`, `PersistedPanel`, `home/SummaryPanel` → contenu séparé proprement du summary (espacement géré par le conteneur, plus d’espaces fantômes).
- Sections spécifiques : `app/admin/school/CollapsibleSection`, `app/teacher/students/[id]/PersistedSection`, `app/teachers/[id]/page.tsx` (bloc photo de profil) harmonisés (pas de `space-y` sur `<details>`, marge sur le contenu).
- Panneaux déjà conformes : `student/injuries`, `student/progress`, `student/agenda`, `teacher/school`, `school/[id]`, `positions` utilisent la règle globale (pas de `space-y` à nettoyer).

## Reste à surveiller
- Si de nouveaux panneaux `<details>` sont introduits, vérifier qu’ils n’utilisent pas de `space-y` sur `<details>` et s’appuient sur la règle globale (ajouter une marge haute sur le contenu si besoin de variante).
