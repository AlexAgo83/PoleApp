# 08_DRY_012 — Suivi élève, droits profs, transferts crédits, détail pack
[Aligné v0.10.8 | Confiance: 60% | Avancement: 0% | Portée: multi-modules (élève/prof/admin/packs)]

## Objectif
Répondre aux retours QA S014 : stats élève pour prof/admin, UX notes collapsée, disciplines multiples pour profs, droits avancés sur création de positions, transferts de crédits entre élèves avec suivi, et fiche détail pack (VOD Cloudinary).

## Portée (in) / (out)
- (in) Fiche élève (vue prof/admin) : stats par élève (positions vues par niveau), notes en édition repliée par défaut (toggle).
- (in) Profil prof : gestion de disciplines multiples, propagation sur pages concernées (affichage/filtrage).
- (in) Gestion des droits profs : option admin pour autoriser/refuser la création de positions.
- (in) Transfert de crédits élève → élève (compte même école) avec traçabilité dans historique achats côté élève et prof/admin (renommage section si besoin).
- (in) Détail pack (VOD Cloudinary) accessible depuis la tuile : template avec titre, durée, player 4:3, chapitres/sommaire, explications courtes, positions liées (pastilles), migration pour remplacer l’URL vidéo obsolète.
- (out) Refonte complète des achats/monétisation ou RBAC global; flux de paiement réel (transfert simulé pour l’instant) ; multi-fichiers hors VOD pack ; analytics avancées.

## Hypothèses / Pré-requis
- Cloudinary déjà en place pour VOD (positions) : on réutilise pour packs (fields `videoUrl`/`videoPublicId` à confirmer/ajouter).
- Transfert de crédits : élèves de la même école uniquement, décrément/incrément atomique et log d’historique (type `TRANSFER_OUT/IN`).
- Stats élève : on peut calculer à partir des positions vues/progression existante (nécessite requêtes agrégées par niveau).
- Droits prof : champ/flag côté user (ex. `canCreatePosition`), configurable par admin.
- UX notes élève : le form existe déjà, on ajoute un collapsible/toggle.

## À faire / Plan
1) **Stats fiche élève (prof/admin)** : ajouter agrégations (positions vues par niveau) + affichage, sans dégrader perfs (pagination/caching éventuel).
2) **Notes collapsées** : ajouter toggle “Modifier les notes” (par défaut fermé) sur fiche élève.
3) **Disciplines multiples prof** : autoriser multi sélection, stockage, affichage (badges) et propagation sur filtres pertinents.
4) **Droits création position** : ajouter flag admin -> contrôles UI (cacher CTA) + garde serveur (actions/route position).
5) **Transfert de crédits** : UI élève (formulaire destinataire + montant), action serveur atomique, logs d’historique pour élève et admin/prof (types d’achats étendus).
6) **Détail pack VOD** : route détail pack (depuis tuile), migration pour Cloudinary video (publicId), player 4:3, champs durée/chapitres/steps/positions liées, remplacement de l’URL vidéo obsolète.
7) QA & a11y : vérifier mobile/desktop, messages d’erreur, libellés clairs.

## Livrables attendus
- Fiche élève enrichie (stats + notes toggle).
- Profil prof avec disciplines multiples propagées.
- Flag droit de création position + enforcement UI/server.
- Transfert crédits avec historique (élève + admin/prof), renommage section si nécessaire.
- Page détail pack avec VOD Cloudinary et template complet, lien depuis tuile.
- Migration/Schéma mis à jour si nouveaux champs (videoPublicId, disciplines, flags).

## Risques / mitigations
- Charge requêtes stats élève : limiter périmètre (page courante), index requis.
- Transferts crédits : cohérence transactionnelle, prévention auto-transfert ou montant négatif.
- Droits prof : oublier un endpoint => ajouter garde côté action/route.
- Migration vidéo packs : compatibilité des données existantes (fallback si pas de videoPublicId).
- UX : trop de champs sur détail pack ; rester concis (chapitres/steps optionnels).
